# vulnfolio 要件定義（ドラフト）

- 更新日: 2026-11-19
- 状態: 対話で合意した要求を記録。詳細な画面仕様・閾値・採用製品は未確定
- 凡例: **合意**＝ユーザー希望として確認済み、**設計案**＝実装候補、**保留**＝追加調査が必要
- 優先度: **P0**＝最初の動くダッシュボード、**P1**＝中核拡張、**P2**＝将来拡張。要求自体を取り消す意味ではない

## 1. 目的・対象利用者

### 1.1 目的（合意）

単なるCVE検索ではなく、情報量を人間が把握できる程度まで機械的に整理し、次のような状況を直感的に把握できるOSSを作る。

1. **次に問題になりそうな脆弱性**：公表前・CVE未採番・SNSで急浮上中を含む
2. **現在問題になっている脆弱性**：悪用確認済み、KEV追加、PoC出現等
3. **自分が確認・対処すべき脆弱性**：管理案件・資産に関連し、未対応・要確認のもの

### 1.2 利用形態（合意）

- 主に個人が利用し、知人等への小規模共有を想定。
- **Webダッシュボード、REST API、MCPサーバー**を目標とする。
- 不特定多数を前提としたSaaS化、マルチテナント、SIEM級の監視機能・運用規模は対象外。
- 個別案件の資産情報・内部構成・対応履歴は共有する公開脆弱性情報と分離し、既定で非公開。

### 1.3 モジュール化・上位APIの統一（合意）

- 外部収集ツールは**Ansible/Vuls/OpenVAS等を同一の共通ジョブAPIから呼び出せる**設計とする。
- ツールごとの入力・出力・検査方式の差異は**中間レイヤーのAdapter/Normalizerで吸収**する。ただし取得できない項目や検査能力の違いは隠蔽せず、Capabilityと欠損/失敗を明示する。
- **収集以外も可能な限りモジュラーにする**。脆弱性ソース、SNS取得元、照合方式、スコア、LLM、公開アダプター等を交換・併用できる設計。
- 初期は単純なモジュラーモノリスとし、すべてをマイクロサービス化したり、すべてのプラグインを初期実装したりはしない。
- 詳細: [モジュール化設計](modularity.md)。

## 4. LLM分析と将来予測

| ID | 要件 | 状態 | 優先 |
| --- | --- | --- | --- |
| AI-01 | 客観的な数値指標は通常のプログラムで計算し、LLMの定性評価と区別する | 合意 | P1 |
| AI-02 | LLMが論点・影響・複数情報の関連・不確実性を要約する | 合意 | P1 |
| AI-03 | **24時間、7日、30日**の動向予測を生成する。**7日間を中心**に見せる | 合意 | P1 |
| AI-04 | 予測作成時点の根拠・期間・モデル/プロンプト版・結果を保存し、後から実績比較する | 合意した方向性 | P1 |
| AI-05 | 通常**1日1回**分析し、異常検知時には追加分析を希望 | 合意 | P1 |
| AI-06 | 追加の従量課金を前提とせず、既存ChatGPT/Claude等の契約枠や無料のローカル推論を検討 | 合意 | P1 |
| AI-07 | サブスクの定期MCP実行が制約される場合は、分析待ちキューと手動実行/次回定期実行で代替 | 設計案 | P1 |

LLMは確認済みの事実を創作・格上げしない。LLMの自己申告の「確信度」を校正済みの客観確率として扱わない。EPSSの30日予測は独立指標として保持し、独自LLM予測と混同しない。

**検証事項:** AIサブスクリプションが自作MCPへのアクセス・書き戻し・定期実行・外部イベント起動にどこまで対応するか。MCPそのものには推論機能・ジョブスケジューラはない。約款・使用制限に抵触する自動化を前提としない。

## 9. 非機能・運用

- **費用:** 追加のAPI従量料金は原則0円を目標とする。電力・ストレージ・既存設備・契約中のサブスクは別。
- **運用:** 個人が無理なく維持できる構成を優先。既存OSS改造・常駐サービス乱立を避ける。
- **可用性:** ソーシャル収集やLLMが停止しても、公式データ収集と既存ダッシュボードは動くようにする。
- **データ保護:** 案件/顧客の識別情報や収集した内部構成を公開レポジトリへ置かない。DB/秘密情報も公開しない。
- **API/スキーマ:** 上流OSSの変更に備え、アダプターで分離。外部API→セルフホストへの移行が可能な構造。
- **ライセンス:** 上流のAGPL等、SNSの再配布条件、モデル・APIの使用条件を都度確認する。
- **品質:** データの出典・最終更新時刻・収集失敗を表示。未確認情報と検証済み情報を混ぜない。

## 10. スコープ外（現段階）

SIEM/EDR級の常時監視、大規模イベントログ管理、全機器への常駐エージェント配布、全ネットワーク機器の自動検出、大規模なマルチテナントSaaS提供、公開利用者の要求ごとのLLM推論。
